# Completionist

Личный трекер прохождения игр. Главная страница показывает коллекцию
и общую статистику, а **у каждой игры своя страница со своим дизайном** —
собственные цвета, шрифты, вёрстка и визуальные эффекты.

Сайт полностью статический: ни сборки, ни зависимостей, ни бэкенда.

---

## Что внутри

**Главная** — агрегированная статистика по всей коллекции: общий процент
закрытых целей, сколько игр пройдено на 100%, суммарные часы, средняя
оценка и распределение по статусам. Плюс сетка карточек с фильтрами
по статусу, поиском и сортировкой.

**Страница игры** — чеклист целей, сгруппированный по смыслу, с живым
пересчётом прогресса. Галочки сохраняются в браузере, так что можно
отмечать выполненное по ходу игры.

**Статусы:** в планах · в процессе · отложено · пройдено · дропнуто.

## Структура

```
├── index.html              главная: статистика и коллекция
├── 404.html
├── data/
│   └── games.js            ЕДИНЫЙ ИСТОЧНИК ПРАВДЫ — все игры и цели
├── assets/
│   ├── css/
│   │   ├── base.css        сброс + каркас чеклиста (общий для всех)
│   │   └── hub.css         оформление главной
│   ├── js/
│   │   ├── core.js         статусы, прогресс, статистика, localStorage
│   │   ├── hub.js          главная: карточки, фильтры, фон
│   │   └── game.js         движок чеклиста для страниц игр
│   └── img/
├── games/
│   ├── elden-ring/         золотой свиток, угли, пергамент
│   ├── cyberpunk-2077/     терминал, неон, глитчи, цифровой дождь
│   ├── hollow-knight/      биолюминесценция, споры, глубина
│   └── starfield/          приборная панель, телеметрия, штамп ABORTED
└── docs/
    └── ADDING-GAMES.md     как добавлять игры и описывать цели
```

Каждая папка в `games/` — три файла: `index.html`, `style.css`, `fx.js`.
Общего между страницами только `base.css` (каркас списка целей) и
`game.js` (логика). Всё остальное пишется под игру с нуля — поэтому
страницы не похожи друг на друга.

## Добавить игру

Подробный контракт — в [docs/ADDING-GAMES.md](docs/ADDING-GAMES.md).
Коротко: достаточно написать в промпте название, статус и, если есть,
свои правила комплишена. Из правил собираются цели, заводится запись
в `data/games.js` и создаётся папка в `games/` со своим дизайном.

Четыре игры в репозитории — примеры. Их можно удалить в любой момент:
скажи об этом, и они уйдут вместе со своими папками.

## Запустить локально

Сайт открывается и просто двойным кликом по `index.html` — данные лежат
в `.js`, а не в `.json`, поэтому `fetch` и CORS не мешают.

Для полноценной проверки лучше поднять сервер:

```bash
python -m http.server 4173
```

Дальше — `http://localhost:4173`.

## Публикация

Сайт выкладывается через GitHub Pages из ветки `main`, папка `/` (корень).
Файл `.nojekyll` отключает обработку Jekyll — она здесь не нужна.

После `git push` в `main` деплой происходит автоматически, обычно
за минуту.

---

## Отметки целей

Галочки на страницах игр живут в `localStorage` браузера и **не меняют**
`data/games.js`. Это сделано специально: можно отмечать прогресс по ходу
игры, не создавая коммитов.

Чтобы зафиксировать прогресс в репозитории — кнопка
**«Скопировать состояние»** на странице игры, затем вставить
скопированное в промпт.

## Доступность и производительность

- Чеклист работает с клавиатуры, у целей выставлены `role="checkbox"`
  и `aria-checked`.
- При системной настройке «уменьшить анимацию» все канвас-эффекты
  и переходы отключаются.
- Канвас-эффекты масштабируют число частиц под площадь экрана,
  так что на мобильных их меньше.
- Шрифты — единственная внешняя загрузка (Google Fonts).
